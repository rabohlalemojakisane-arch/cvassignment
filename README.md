# Professional CV - React Application

## Project Description
A professional online Curriculum Vitae (CV) built with React.js, featuring a clean design, responsive layout, and interactive features.

## Technologies Used
- React.js
- React Hooks (useState, useEffect, useRef)
- CSS3
- JavaScript (ES6)
- html2pdf.js

## Features
- Professional CV layout with all sections
- Dark/Light Mode toggle
- Show/Hide Skills
- Print CV button
- Download CV as PDF button
- Responsive design (works on all devices)
- Dynamic document title

## Sections Included
- Header with name, title and contact info
- Profile summary
- Education
- Skills
- Work Experience
- Projects
- References
- Footer with copyright
